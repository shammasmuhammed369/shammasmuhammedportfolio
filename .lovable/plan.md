# Interdisciplinary Portfolio

## Overview
Build a responsive, static multi-page portfolio presenting Muhammad Shammas N as a developing interdisciplinary student across cybersecurity, sociology, and Islamic jurisprudence. The site will use a restrained dark academic-technical visual system, clear content hierarchy, and subtle accessible motion.

## Pages and navigation
- Create dedicated pages for Home, About, Cybersecurity, Projects, Research, Writing, Education, and Contact.
- Add a consistent desktop and mobile navigation bar, active-page indicator, and footer.
- Keep contact details and external profiles as clearly marked placeholders until real links are supplied.

## Content
- Use the supplied wording and positioning without inventing credentials, institutions, dates, findings, publications, or achievements.
- Build the cybersecurity profile around learning stages: Foundation, Beginner, and Developing.
- Create detailed project entries with a consistent Problem → Future improvements structure.
- Distinguish active projects from Planned / Coming Soon work.
- Present the Gaza-related topic as an academic research project with unfilled research fields and no invented conclusions.
- Clearly label interdisciplinary themes as research interests and future directions.
- Separate formal education from professional and independent learning.

## Visual and interaction design
- Use a charcoal and neutral palette with one restrained teal accent, strong editorial typography, thin borders, and generous spacing.
- Create an abstract, lightweight hero diagram linking Security, Society, and Law & Ethics.
- Add gentle entrance transitions, staggered cards, restrained hover movement, and an animated navigation marker.
- Respect reduced-motion preferences and keep the mobile experience compact and readable.

## Technical details
- Use TanStack Start routes and shared React components with no backend, database, authentication, analytics, or contact-form data collection.
- Use semantic HTML, keyboard-accessible controls, visible focus states, secure external-link attributes, and page-specific metadata.
- Keep dependencies minimal and use CSS for motion and the abstract visual.
- Add project documentation describing security choices: no secrets, no unnecessary collection, no unsafe external scripts, and safe outbound links.
- Verify desktop and mobile layouts, route navigation, reduced-motion behavior, and page metadata.
